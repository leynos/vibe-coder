# Vibe Coder ADR pack

This archive contains a proposed Architecture Decision Record pack for the Vibe
Coder idle game. The files are intended to be copied into a repository `docs/`
directory. All decision records are marked `Proposed` so that maintainers can
ratify, edit, or reject them during review.
